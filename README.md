# Humanizer-zh — 中文 AI 写作去 AI 化 Skill

`humanizer-zh` 是一个面向 AI 编程助手 / Agent 的中文文本改写技能（Skill）。核心任务是识别并去除 AI 生成痕迹，让中文文本读起来更自然、更像真人写作，同时严格保证**事实与核心观点不被改变**。

适用于论文、报告、方案、邮件、新媒体文案等文本的润色与改写。

## 特性

- **双版本输出**：默认产出「稳健版」（保守改写、风险最低）与「自然版」（更口语化、更有节奏）两版改写稿
- **AI 痕迹诊断**：内置 32 类 AI 痕迹词典（夸大意义、宣传腔、模糊归因、三段式强迫列举、连接词堆叠、否定式排比、口号化对偶、数据缺锚点等），输出 3–6 条主要问题清单
- **分层改写**：按「段落 → 句子 → 词语」三层处理，替换模板词、打散长句、删除重复段意
- **人类风格校准**：节奏、视角、温度、具体性、可证性、冗余度 6 项校准
- **一致性复核**：事实、数字、时间、人名、机构、术语逐项核对
- **质量评分**：50 分制（直接性 / 节奏 / 信任度 / 真实性 / 精炼度），便于复核与二次改写决策
- **底线约束**：不编造数据、来源、引文；信息缺口用「【需确认】」标注，不自行补全

## 工作流程

1. **确认输入**：受众、语体语气、长度目标、不可改动项、风险偏好 5 项；缺失时先追问 2–4 个关键问题
2. **诊断 AI 痕迹**：按 32 类词典扫描并输出主要问题清单
3. **确定改写策略**：按文本类型（学术 / 商务 / 内容传播）与风险偏好（保守 / 平衡 / 激进）分路
4. **分层改写 + 人类风格校准**：段落 → 句子 → 词语，再按 6 项做风格校准
5. **一致性复核**：确保事实零丢失、零杜撰、术语前后一致
6. **按固定格式输出**：诊断摘要 → 稳健版 → 自然版 → 关键改动说明 → 质量评分 → 风险提示

## 快速使用

将本项目（`SKILL.md` 所在目录）放入 AI 助手可识别的技能目录，然后向 AI 发起类似请求：

> 把这段论文摘要去 AI 味，保持学术严谨，等长输出。

> 这份汇报材料太像模板文，改成管理层可快速阅读的版本。

> 保留事实不变，把下面文案改得更像真实作者写的。

## 文件结构

```
Humanizer-zh/
├── SKILL.md        # 技能入口文件（AI 读取此文件执行改写流程）
└── SKILL参考.md     # 参考文档：AI 痕迹特征清单与改写规则详解
```

## 设计来源

- `SKILL.md` 提供可执行的中文改写工作流与完成标准
- `SKILL参考.md` 译自 [blader/humanizer](https://github.com/blader/humanizer)，参考 hardikpandya/stop-slop，基于维基百科 [Signs of AI writing](https://en.wikipedia.org/wiki/Signs_of_AI_writing)（WikiProject AI Cleanup 维护）

## 边界与合规

- 不得捏造数据、来源、案例、引文
- 不得改变用户明确要求保留的术语与结论
- 不得用华丽辞藻掩盖信息不足
